🧬 Module 6: XSS - แพ็กเก็ตแฝงสคริปต์ ทำงานในเบราว์เซอร์ของเหยื่อ
ต่างจาก SQLi ที่โจมตี "เซิร์ฟเวอร์" ช่องโหว่ XSS (Cross-Site Scripting) คือการฝังโค้ด JavaScript ลงในหน้าเว็บ แล้วให้ "เบราว์เซอร์ของเหยื่อ" เป็นคนรันโค้ดนั้นเอง:
• Stored XSS: เพย์โหลดถูกบันทึกไว้ในเซิร์ฟเวอร์ถาวร (เช่น ช่องคอมเมนต์) ทุกคนที่เปิดหน้านั้นจะโดนรันสคริปต์
• Reflected XSS: เพย์โหลดอยู่ใน URL ต้องหลอกให้เหยื่อคลิกลิงก์ก่อน สคริปต์ถึงจะสะท้อนกลับมารัน

⚡ Module 9: Chained Attacks - มหาเวทคอมโบส่งแพ็กเก็ต 2 จังหวะสู่ RCE

• Packet 1 (Poisoning): ส่งแพ็กเก็ตฝังโค้ด PHP Shell ใน User-Agent เข้าไปใน access.log
