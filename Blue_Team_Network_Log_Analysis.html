🦈 1. การวิเคราะห์ไฟล์ Packet Capture (PCAP) ด้วย Wireshark
ในการแข่งขัน CTF และงานสืบสวนศูนย์ SOC ไฟล์ .pcap / .pcapng คือบันทึกการเดินทางของทุกแพ็กเก็ตในเครือข่าย

Cheat Sheet
  • http.request.method == "POST": กรองหาคำขอที่ผู้ใช้ส่งข้อมูลเข้าระบบ (เช่น Login form, File Upload)
  • ip.addr == 192.168.1.100: กรองดูเฉพาะการสื่อสารของเครื่องเป้าหมาย
  • tcp contains "flag{" หรือ frame contains "password": ค้นหาคำสำคัญในเนื้อแพ็กเก็ต
  • dns.flags.response == 0: ส่องดูการส่ง DNS Query (ตรวจหา DNS Exfiltration / C2 Tunneling)
🔓 2. อันตรายของ Unencrypted Protocols & การดักจับ Cleartext Password
เมื่อข้อมูลวิ่งผ่านเครือข่ายด้วยโปรโตคอลที่ไม่มีการเข้ารหัส เช่น HTTP, FTP, Telnet, หรือ SNMP v1/v2
ผู้ดักฟัง (Attacker หรือ Blue Team Sniffer) สามารถดึง Username และ Password ออกมาเป็นข้อความอ่านได้ทันที!
📡 ส่องรหัสผ่านหลุดในแต่ละโปรโตคอลคลาสสิก
Plaintext Protocols
1. HTTP (พอร์ต 80)
ฟอร์มล็อกอินส่ง Body: uname=admin&pwd=P@ssw0rd2026 ในแพ็กเก็ต POST
2. FTP (พอร์ต 21)
ส่งคำสั่ง USER root และ PASS SuperSecret123 เป็น Plaintext ตัวอักษรตรงๆ
3. Telnet (พอร์ต 23)
ส่งตัวอักษรทีละคีย์สโตรก แฮกเกอร์ร้อยเรียงคำอ่านรหัสผ่านทั้งชุดได้ 100%
🐧 3. CLI Log Hunting — บรรทัดคำสั่ง Linux ตรวจสอบคนร้ายจาก Web & Auth Log
เมื่อเกิดเหตุบุกรุก เซิร์ฟเวอร์ขนาดใหญ่อาจมี Log นับล้านบรรทัด การเปิดดูด้วยตาเปล่าเป็นไปไม่ได้!
อาวุธคู่กายของ SOC Analyst และ Blue Team คือการผสมคำสั่ง grep, awk, sort, uniq, และ cut เพื่อบีบหา IP คนร้ายใน 5 วินาที
⚡ Interactive Command-Line Log Investigation Pipeline

คลิกเลือกคำสั่ง CLI ด้านล่างเพื่อดูผลลัพธ์การคัดกรอง IP แฮกเกอร์ที่พยายามโจมตี Web Server

📚 คัมภีร์ Pipeline อมตะ 5 สเต็ปของ Blue Team
One-Liner Mastery
# นับจำนวน Request แยกตาม IP และเรียงจากมากไปน้อย:
cat access.log | awk '{print $1}' | sort | uniq -c | sort -nr | head -n 10

# หาคนร้ายที่พยายามสแกนรหัสผ่าน SSH ล้มเหลว (Failed password):
grep "Failed password" /var/log/auth.log | awk '{print $(NF-3)}' | sort | uniq -c | sort -nr
🚨 4. Web & Auth Log Forensics — การแกะรอยการโจมตีจริงผ่าน Log
Log เปรียบเสมือนรอยเท้าของคนร้ายในที่เกิดเหตุ การเข้าใจรูปแบบการบันทึกของ Nginx / Apache (access.log) และ Linux Authentication (auth.log) ช่วยให้เราระบุเวลาเกิดเหตุ (Timeline) และผลกระทบได้อย่างแม่นยำ
📊 สัญญาณเตือนภัยใน Log แต่ละประเภท
Attack Signatures
  • SSH Brute Force: พบคำว่า Failed password for invalid user หรือ Failed password for root นับพันครั้งในเวลาไม่กี่นาทีจาก IP เดิม
  • SQL Injection: พบตัวอักษร %27 (' ), UNION+SELECT, หรือ SLEEP(5) ใน URL Query String
  • Directory Fuzzing: พบคำขอเข้าถึงไฟล์แปลกๆ /admin/, /config.php.bak, /.git/ ติดต่อกันรัวๆ พร้อม Status 404
  • Web Shell Execution: พบคำขอเข้าถึงไฟล์แปลกปลอมในโฟลเดอร์อัปโหลด เช่น GET /uploads/avatar.php?cmd=whoami พร้อม Status 200
